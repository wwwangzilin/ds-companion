她开始有自己的日子了：日记、状态曲线，还有半夜不打扰的开关。

**直接跑**：下 `ds-companion-v0.2.0-dev-x64.exe`（单文件；Windows + WebView2，系统自带）。
第一次运行是空数据目录 —— 用你自己的 DeepSeek 登录态。

## 她自己写日记

- 一天一篇 `diary/<角色>/YYYY-MM-DD.md`，**在第二天的第一次聊天里回顾前一天**（今天还没过完，没什么可写的）
- 正文由模型用**她自己的口吻**写，素材是「哪天 + 聊了几轮 + 当时好感 + 那天的对话节选」；
  壳只负责挑日子与落盘（注入脚本跑在远程页面里，一个文件系统能力都不给它）
- 设置页 → 状态 新增「她的日记」卡片：列出她有日记的日子，点一天看那天她写了什么
- 三条边界都不许松：**不进记忆库**（否则越写越像照镜子）、**不注入回对话**（否则她会为了被看见而表演写日记）、
  一天一个文件（拿记事本直接打开就是完整一篇）

## 她的状态曲线

- 一天一行（最多留 90 天），两条线：粉线 = 好感，蓝线 = 当天情绪均值
- 少于两天就明说「还画不出」——**绝不画一条假线糊弄过去**

## 空闲主动：时间终于能自己定了

- **安静时段**（例如 `23 → 8`，跨零点也行）：这两个小时之间她不会主动开口
- **每天最多几次**搬到了界面上（`0` = 不限）
- 两个新旋钮**默认都不改既有行为**：时段留空 = 全天都能说

## 顺手修掉的

- **被拒的时候不扣额度**：安静时段这道闸排在额度之前，半夜不会白烧额度（验收脚本专门盯这条）
- **写配置的竞态**：连着改两个闸门时，后一次保存会把前一次的改动一起带回去（读-改-写）——加了一条写队列
- **发版门禁漏了一份测试**：`test-diary.cjs` 不在 release 的清单里，等于"发出去的包没跑过它"

## 工程

- CI 每 push 一跑：192 个 Rust 单测 + 2 个集成测试（真实落盘；集成测试是独立进程，先换掉 `DSC_DATA_DIR`
  再动手，一个字节都不碰 `%APPDATA%`）+ 5 份注入脚本单测 + 构建
- 推 `v*` tag 即自动出包（这一版就是这么发的）
